Test your own 3D model

Drop a .glb file onto the viewer or choose one here. Draco and Meshopt compressed models are supported. The viewer reports the model's size and estimated memory use. No size or polygon limits have been approved yet (P-09).

What changed in v2

  • The viewer is rebuilt on React Three Fiber, over the same three.js r160.
  • The product image shows first; 3D replaces it whenever it finishes loading, however long that takes.
  • Draco models load with decoder files hosted alongside this page.
  • Bad or unsupported files always end in a clear message.

Built to keep shopping safe

  • The 3D viewer runs in isolation. If it fails, product info, sizes and Add to bag still work (§6.3).
  • 3D stops rendering whenever it isn't visible.
  • Swipe up or down on the viewer to scroll the page; swipe sideways to rotate.
  • Arrow keys rotate the 3D view once it has keyboard focus.
