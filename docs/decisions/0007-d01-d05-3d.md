# 0007 — D-01 to D-05: 3D product experience

Date: 5 November 2026 · Decided by: Talha (product owner) · Blueprint: MTS v2.1 §4, §17, §18 (M6)
Status: **APPROVED** exactly as recommended

| ID | Decision |
| --- | --- |
| D-01 | **No final asset budget yet** (A-13 stands). The pipeline measures every model and shows staff a **warning, never a refusal**, above provisional figures: compressed file > 8 MB, > 150,000 triangles, a texture > 2048 px, estimated GPU memory > 150 MB. No automatic texture resizing. The final limits are set from V-01 and V-02 before 3D is switched on; the provisional figures are not performance limits. |
| D-02 | **Draco** is the standard compression, with WebP textures. The viewer still reads Meshopt models (decoder only where WebAssembly is allowed). Confirmed after the V-02 measurements. |
| D-03 | **One model per garment, colours as glTF material variants (`KHR_materials_variants`)**, each variant named by the colour's slug (`ivory`, `sage`). A colour may have its own model when its shape differs. A colour without a 3D version shows its photos. |
| D-04 | **An external garment-3D specialist using CLO 3D or Marvelous Designer**, to AureVon's delivery spec (GLB, variants named as in D-03, metres, centred, no lights, cameras or animation). One pilot garment first, which also serves as V-02. Sourcing the specialist is the owner's action. |
| D-05 | **The wheel scrolls the page; Ctrl or ⌘ + wheel zooms** (trackpad pinch arrives as Ctrl + wheel). On-screen + and − buttons; a one-time hint. Touch pinch unchanged. |

Unchanged: 3D stays **off for shoppers** until V-01, V-02 and V-03 pass (MTS §17); product pages always work with
images alone (A-14). MTS v2.1 is not edited; the next revision folds these into the approved register.
